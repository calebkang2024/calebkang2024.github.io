# Caleb Kang — Portfolio Website

A responsive, dark-themed personal portfolio built with plain HTML, CSS, and JavaScript for GitHub Pages.

## Publish with GitHub Pages

1. Create a **public** repository named `calebkang2024.github.io`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository's top level (the root).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. After GitHub finishes publishing, visit `https://calebkang2024.github.io`.

## Personalize before sharing

- Add your preferred professional email in the contact section of `index.html`.
- Add a résumé PDF to the repository (for example, `assets/Caleb-Kang-Resume.pdf`) and add a link to it.
- Replace the Unity project placeholder with screenshots, a short demo video, or a project page when you have material ready.
- Add links to public code repositories only when the code is ready to share.
- Review every description for accuracy before publishing. The Unity project section intentionally describes AI-assisted implementation transparently.

## Edit the site

- `index.html` contains the text and page structure.
- `styles.css` controls colors, layout, typography, and responsive styling.
- `script.js` controls the mobile navigation menu.

No build tools or dependencies are required. The Google Fonts import is optional; the page uses system sans-serif fallbacks if fonts cannot load.
